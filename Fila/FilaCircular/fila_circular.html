Fila Circular: Espaço de Segurança

Esta visualização demonstra a Fila Circular utilizando a abordagem de Espaço de Segurança. Para distinguir uma fila vazia (front == rear) de uma fila cheia ((rear + 1) % SIZE == front), sacrificamos um espaço no array, que permanece sempre vazio. Assim, um array de tamanho N guarda, no máximo, N-1 elementos.

Código em C (Espaço de Segurança)
// Inicialização: Front e Rear apontam para 0 int front = 0; int rear = 0;
void enqueue(int value) {
if ((rear + 1) % SIZE == front) {
printf("Erro: Fila cheia!\n");
return;
}
queue[rear] = value;
rear = (rear + 1) % SIZE;
}
int dequeue() {
if (front == rear) {
printf("Erro: Fila vazia!\n");
return -1;
}
int value = queue[front];
front = (front + 1) % SIZE;
return value;
}
