Selection Sort (Em C)

O Selection Sort divide a lista em uma parte ordenada e outra não ordenada. Ele continuamente procura pelo menor elemento da parte não ordenada e o "seleciona" para trocá-lo com o primeiro elemento disponível, garantindo o mínimo de trocas na memória.

#include <stdio.h>




void selectionSort(int arr[], int n) {


    int i, j, min_idx, temp;


    for (i = 0; i < n - 1; i++) {


        // Assume que o primeiro não ordenado é o menor


        min_idx = i;


        


        for (j = i + 1; j < n; j++) {


            if (arr[j] < arr[min_idx]) {


                min_idx = j;


            }


        }


        


        // Se o menor não for o da posição atual, troca


        if (min_idx != i) {


            temp = arr[i];


            arr[i] = arr[min_idx];


            arr[min_idx] = temp;


        }


    }


}
