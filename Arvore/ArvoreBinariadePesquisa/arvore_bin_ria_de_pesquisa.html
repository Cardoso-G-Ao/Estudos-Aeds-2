Uma BST organiza dados para pesquisa rápida. O filho esquerdo é sempre menor que o pai, e o direito é maior. Profundidade máxima visual: 4 níveis.

Node* search(Node* root, int val) {
if (root == NULL || root->data == val)
return root;
if (val < root->data)
return search(root->left, val);
return search(root->right, val);
}
