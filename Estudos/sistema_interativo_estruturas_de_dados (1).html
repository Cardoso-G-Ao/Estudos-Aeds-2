Tópico 1

Lista Linear Sequencial

Armazenamento contíguo em vetor de capacidade fixa com deslocamento de elementos.

Complexidade: Inserir/Remover Fim: $\Theta(1)$ Início/Meio: $\Theta(n)$

Simulador Interativo da Lista

Capacidade do Vetor: 6 elementos | Tamanho atual ($n$): 0
Pronto. Digite um valor e execute uma operação.
Representação da Memória (Vetor `vet`):

💡 Conceitos Fundamentais

  • Tipo Abstrato de Dados (TAD): Armazena dados de forma sequencial na memória através de um vetor (`vet`) e mantém uma variável inteira $n$ que representa a quantidade atual de elementos.
  • Deslocamento de Elementos (Shifting): Na inserção no início ou em posição arbitrária $pos$, é necessário mover todos os elementos existentes de $[pos..n-1]$ uma posição para a direita ($vet[i] = vet[i-1]$). Na remoção, os elementos à direita são deslocados uma posição para a esquerda ($vet[i] = vet[i+1]$).
  • Controle de Limites: Sempre verifica estouro ($n \ge vet.length$) na inserção ou sobrefluxo ($n == 0$) na remoção.
Código Implementado 
class Lista {
    private int[] vet;
    private int n;

    public Lista(int tamanho) {
        vet = new int[tamanho];
        n = 0;
    }

    public void inserirInicio(int x) throws Exception {
        if (n >= vet.length) throw new Exception("Erro!");
        for (int i = n; i > 0; i--) {
            vet[i] = vet[i - 1];
        }
        vet[0] = x;
        n++;
    }
}

Tópico 2

Pilha Linear Sequencial (LIFO)

Last-In, First-Out (O último a entrar é o primeiro a sair). Inserção e remoção no topo.

Complexidade: Empilhar / Desempilhar: $\Theta(1)$

Simulador da Pilha

Ponteiro Topo ($n$): 0 / 6
Pilha vazia. Insira elementos no topo.

📌 Regras da Pilha

A pilha sequencial utiliza uma única variável contador $n$ que aponta para a próxima posição livre no topo do vetor:

  • Empilhar (push): Atribui vet[n] = x e incrementa n++. Ocorre em tempo constante $\Theta(1)$.
  • Desempilhar (pop): Decrementa n-- e retorna vet[n]. Também ocorre em tempo constante $\Theta(1)$.
  • Aplicações comuns: Avaliação de expressões matemáticas, controle da pilha de chamadas recursivas de funções, refazer/desfazer em editores.
Código Pilha 
class Pilha {
    private int[] vet;
    private int n;

    public void inserir(int x) throws Exception {
        if (n >= vet.length) throw new Exception("Erro!");
        vet[n] = x;
        n++;
    }

    public int remover() throws Exception {
        if (n == 0) throw new Exception("Erro!");
        return vet[--n];
    }
}
int vet[MAX];
int n = 0;

void inserir(int x) {
    if (n >= MAX) return;
    vet[n++] = x;
}

int remover() {
    if (n == 0) return -1;
    return vet[--n];
}
Tópico 3

Fila Circular Sequencial (FIFO)

First-In, First-Out (O primeiro que entra é o primeiro a sair). Incremento circular $(i + 1) \% N$.

Complexidade: Enfileirar / Desenfileirar: $\Theta(1)$

Simulador de Fila Circular

Primeiro: 0 Último: 0
Fila pronta. A rotação circular reaproveita posições liberadas sem mover elementos!

🔄 Como Funciona o Reuso Circular?

Na fila sequencial comum, remover do início custaria $\Theta(n)$ para mover os elementos. Na Fila Circular, usamos o operador módulo $\%$ para efetuar o "wrap-around":

ultimo = (ultimo + 1) % N;
primeiro = (primeiro + 1) % N;

Desta forma, quando um ponteiro atinge o fim do vetor ($N-1$), ele retorna à posição $0$ caso haja espaço disponível, garantindo operações $\Theta(1)$.

Código Fila Circular 
public void inserir(int x) throws Exception {
    if (((ultimo + 1) % vet.length) == primeiro)
        throw new Exception("Fila Cheia!");
    vet[ultimo] = x;
    ultimo = (ultimo + 1) % vet.length;
}

public int remover() throws Exception {
    if (primeiro == ultimo)
        throw new Exception("Fila Vazia!");
    int resp = vet[primeiro];
    primeiro = (primeiro + 1) % vet.length;
    return resp;
}
