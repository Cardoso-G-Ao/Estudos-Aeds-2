Métodos de Pesquisa: Sequencial vs. Binária

A recuperação de dados é uma das operações operacionais mais elementares da computação. Enquanto a pesquisa sequencial varre a coleção elemento a elemento sem exigências prévias, a pesquisa binária aproveita a ordenação dos dados para dividir o espaço de busca pela metade a cada passo, alcançando eficiência logarítmica. Estruturas de Dados Lineares e Memória Dinâmica

O gerenciamento dinâmico na Heap via ponteiros possibilita a criação de coleções flexíveis que expandem e contraem em tempo de execução, superando a rigidez dos arranjos estáticos. Esta seção analisa o funcionamento das disciplinas de acesso LIFO (Pilha) e FIFO (Fila), detalhando o controle por células autorreferenciáveis e prevenindo falhas críticas como vazamentos de memória e acessos inválidos (*segmentation fault*).

Algoritmos de Ordenação Sequenciais e Paralelos

A ordenação organiza elementos conforme uma relação de ordem total. Enquanto métodos quadráticos simples ($O(n^2)$) atendem a pequenos volumes, algoritmos logarítmicos ($O(n \log n)$) baseados em Divisão e Conquista dominam cenários complexos. Para supercomputação e dados massivos, estratégias paralelas exploram múltiplos núcleos, com ganho limitado pelo gargalo de sincronização expresso pela **Lei de Amdahl**.

Catálogo de Algoritmos e Estratégias

Bubble Sort O(n²)

Trocas diretas entre vizinhos. Ineficiente para grandes listas. Estável.

Paralelização: Odd-Even Transposition
Insertion Sort O(n²)

Inserção direta. Desempenho linear O(n) excelente em coleções quase ordenadas.

Paralelização: Blocos / Pipelines
Merge Sort O(n log n)

Divisão e Conquista. Intercalação estável que garante tempo assintótico perfeito em todos os cenários.

Memória Auxiliar: O(n)
Quick Sort O(n log n)

Particionamento em torno de pivô. Desempenho prático sequencial superior. In-place.

Pior caso: O(n²) se pivô inadequado
Bitonic Sort Redes Paralelas

Construído para redes de comparação e paralelismo massivo em GPUs e arquiteturas multicore.

Complexidade: O(n log² n)
Sample Sort Distribuído

Amostragem para balanceamento de carga e distribuição de dados entre nós de rede independentes.

Foco: Memória Distribuída

Simulador da Lei de Amdahl (Speedup Limit)

Análise Paralela

A fórmula $S_p = \frac{1}{(1-P) + \frac{P}{p}}$ demonstra como a fração estritamente sequencial $(1-P)$ limita o aceleração máxima, mesmo com número infinito de processadores.

Métricas de Desempenho

Speedup Máximo Teórico (p → ∞) 10.0x Limitado pelos 10% de código sequencial.
Eficiência com 16 Processadores 41.2% Perda por gargalo de sincronização e comunicação.
Gargalos no Processamento Paralelo

Além do limite teórico de Amdahl, o ganho real de velocidade é atenuado pela sobrecarga de comunicação entre threads e contenção de barramento de memória.
