Tópico 1

Lista Duplamente Encadeada

Nós contendo referências bidirecionais (ant e prox) permitindo travessia nos dois sentidos.

Complexidade: Início/Fim: $\Theta(1)$ Busca: $\Theta(n)$

Simulador da Lista Dupla

Total de Elementos: 3
Pronto. Cadê nó mantém referências duplas ant e prox.

💡 Características Principais

  • Nó Duplo: Cada célula armazena elemento, prox (próximo nó) e ant (nó anterior).
  • Remoção no Fim em $\Theta(1)$: Diferente da lista simplesmente encadeada, a remoção no fim é eficiente pois podemos acessar o penúltimo nó diretamente via ultimo.ant sem precisar percorrer a lista inteira.
  • Uso de Nó Cabeça: Facilita a manipulação e elimina casos especiais de lista vazia.
Código Lista Dupla 
class CelulaDupla {
    public int elemento;
    public CelulaDupla ant, prox;

    public CelulaDupla(int x) {
        this.elemento = x;
        this.ant = this.prox = null;
    }
}

public void inserirFim(int x) {
    ultimo.prox = new CelulaDupla(x);
    ultimo.prox.ant = ultimo;
    ultimo = ultimo.prox;
}
typedef struct CelulaDupla {
    int elemento;
    struct CelulaDupla *ant, *prox;
} CelulaDupla;

void inserirFim(int x) {
    ultimo->prox = novaCelulaDupla(x);
    ultimo->prox->ant = ultimo;
    ultimo = ultimo->prox;
}
Tópico 2

Pilha Encadeada Flexível

Alocação dinâmica em estrutura LIFO sem tamanho fixo pré-definido.

Complexidade: Push / Pop: $\Theta(1)$

Simulador da Pilha Flexível

Ponteiro topo
Pilha flexível pronta.

📌 Operações de Ponteiro

Na pilha flexível, o empilhamento faz o novo nó apontar para o topo atual, e atualiza o topo para o novo nó:

Celula tmp = new Celula(x);
tmp.prox = topo;
topo = tmp;

Na desempilhação, salvamos o elemento, avançamos topo = topo.prox e liberamos o nó desempilhado.

Código Pilha Flexível 
public void inserir(int x) {
    Celula tmp = new Celula(x);
    tmp.prox = topo;
    topo = tmp;
}

public int remover() throws Exception {
    if (topo == null) throw new Exception("Erro!");
    int elemento = topo.elemento;
    Celula tmp = topo;
    topo = topo.prox;
    tmp.prox = null;
    return elemento;
}
void inserir(int x) {
    Celula *tmp = novaCelula(x);
    tmp->prox = topo;
    topo = tmp;
}

int remover() {
    if (topo == NULL) errx(1, "Erro!");
    int elemento = topo->elemento;
    Celula *tmp = topo;
    topo = topo->prox;
    free(tmp);
    return elemento;
}
Tópico 3

Árvore Binária de Busca (BST)

Hierarquia onde subárvores à esquerda contêm valores menores e à direita contêm valores maiores.

Complexidade: Busca Média: $\Theta(\log n)$ Pior Caso: $\Theta(n)$

Simulador e Percursos na Árvore

Árvore inicializada com a raiz [40].

🌲 Algoritmos de Percurso

  • Em-Ordem (Central): Visita subárvore Esquerda $\rightarrow$ Raiz $\rightarrow$ Direita. Produz a sequência estritamente ordenada em uma BST.
  • Pré-Ordem (Caminhamento): Visita Raiz $\rightarrow$ Esquerda $\rightarrow$ Direita. Útil para clonagem de árvores.
  • Pós-Ordem: Visita Esquerda $\rightarrow$ Direita $\rightarrow$ Raiz. Útil para liberação de memória em C ou cálculo de espaço ocupado.
Código BST (Inserção & Pesquisa) 
public boolean pesquisar(int x, No i) {
    if (i == null) return false;
    else if (x == i.elemento) return true;
    else if (x < i.elemento) return pesquisar(x, i.esq);
    else return pesquisar(x, i.dir);
}

public void caminharCentral(No i) {
    if (i != null) {
        caminharCentral(i.esq);
        System.out.print(i.elemento + " ");
        caminharCentral(i.dir);
    }
}
bool pesquisar(int x, No *i) {
    if (i == NULL) return false;
    else if (x == i->elemento) return true;
    else if (x < i->elemento) return pesquisar(x, i->esq);
    else return pesquisar(x, i->dir);
}
Tópico 4

Tabela Hash (Dispersão com Encadeamento)

Mapeamento direto por função Hash $h(k) = k \bmod M$ e lista encadeada para tratar colisões.

Complexidade: Médio: $\Theta(1)$ Pior Caso: $\Theta(n)$

Simulador da Tabela Hash ($M = 5$)

Função: pos = chave % 5
Tabela Hash com 5 compartimentos (buckets) pronta.

⚡ Tratamento de Colisões

Quando duas chaves diferentes geram a mesma posição $h(k_1) = h(k_2)$, ocorre uma colisão.

No Encadeamento Direto (External Chaining), cada posição da tabela guarda uma lista flexível encadeada contendo todos os elementos mapeados para aquele índice.

Código Hash com Lista 
public int hash(int elemento) {
    return elemento % tabela.length;
}

public boolean pesquisar(int x) {
    int pos = hash(x);
    return tabela[pos].pesquisar(x);
}

}

    int pos = hash(x);
